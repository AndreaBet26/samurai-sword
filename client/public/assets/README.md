# 🎨 Guida Inserimento Immagini Originali

In questa cartella puoi inserire le scansioni o immagini originali delle carte e dei personaggi del gioco.

Il sistema carica automaticamente le immagini in base al nome del file (formato `.webp`, circa 750×1000 px; gli originali ad alta risoluzione sono nella cartella `assets_originali` del progetto). Se un'immagine non è presente, il gioco mostrerà automaticamente la splendida illustrazione vettoriale predefinita con bordi ufficiali e finitura lucida.
